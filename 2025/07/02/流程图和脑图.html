Mermaid流程图和脑图语法渲染示例

2025-07-02
3 min read

脑图示例

在这篇文章中，我们将使用 Mermaid 创建不同形式的脑图。

1. 基本脑图

graph TD;
    A[主题] --> B[子主题1];
    A --> C[子主题2];
    B --> D[子子主题1.1];
    B --> E[子子主题1.2];
    C --> F[子子主题2.1];

2. 带有样式的脑图

graph TD;
    A[主题] -->|连接| B[子主题1];
    A -->|连接| C[子主题2];
    B --> D[子子主题1.1];
    B --> E[子子主题1.2];
    C --> F[子子主题2.1];

    style A fill:#f9f,stroke:#333,stroke-width:4px;
    style B fill:#ccf,stroke:#333,stroke-width:2px;
    style C fill:#ccf,stroke:#333,stroke-width:2px;

3. 复杂脑图

graph TD;
    A[主题] --> B[子主题1];
    A --> C[子主题2];
    B --> D[子子主题1.1];
    B --> E[子子主题1.2];
    C --> F[子子主题2.1];
    C --> G[子子主题2.2];
    D --> H[子子子主题1.1.1];
    E --> I[子子子主题1.2.1];

    style A fill:#ffcc00,stroke:#333,stroke-width:4px;
    style B fill:#66ccff,stroke:#333,stroke-width:2px;
    style C fill:#66ccff,stroke:#333,stroke-width:2px;
    style D fill:#99ff99,stroke:#333,stroke-width:1px;
    style E fill:#99ff99,stroke:#333,stroke-width:1px;
